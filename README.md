# Medication Tracker

Generic, installable GitHub Pages medication tracker.

## Privacy

The public repository contains no patient name, diagnosis, medications, doses, dates, clinic information, or owner information. A private JSON configuration is imported in the browser and stored locally. Dose history is not uploaded.

## Features

- Next-dose countdown
- Large phone-friendly controls
- Selectable dose amounts
- Clearly labeled as-needed medications that remain available without becoming overdue
- Local dose history
- Full JSON backup and restore
- CSV export
- Daily backup reminder
- Offline PWA after first load

## Deployment

Publish the repository root through GitHub Pages.
